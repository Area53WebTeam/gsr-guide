# A GSR's Guide to Being Heard in Area 53

A plain-language, mobile-friendly guide for General Service Representatives (GSRs) on how Area 53 does business — how ideas get to the Assembly floor, how motions work, and how substantial unanimity and minority opinion are handled.

This is a single self-contained HTML page — no build step, no dependencies, and no tracking. It's meant to be read on a phone at the microphone as easily as on a laptop at home.

## View it live

Once this repo is published with GitHub Pages enabled (Settings → Pages → deploy from the `main` branch, root folder), the guide will be available at:

```
https://<your-username>.github.io/<repo-name>/
```

If the guide's file isn't already named `index.html`, rename it so GitHub Pages serves it as the site's home page.

## What's inside

- Collapsible sections for each chapter, with a jump-to-section menu and a reading-progress bar
- A searchable quick reference for plain-language motions (Section 4)
- A tabbed walkthrough for getting an idea to the Assembly floor, depending on whether your district has an active DCM (Section 3)
- A visual walkthrough of the minority-opinion and motion-to-reconsider process (Section 5)
- An interactive worksheet that assembles a plain-language motion from a fill-in-the-blank template, with one-click copy (Section 6) — everything typed there stays in the browser tab and is never saved or sent anywhere

## Editing

Everything — markup, styles, and script — lives in the one HTML file, so it can be opened directly in any text editor. There's no build process to run; just edit and refresh.

## About this guide

This guide is offered as a helpful reference from the Area 53 Chairperson's desk — it is not Area 53 policy, and it isn't A.A. Conference-approved literature. Where it touches procedure not spelled out in the Area 53 Guidelines or the A.A. Service Manual, check with the Chairperson, Delegate, or the relevant committee rather than relying on this alone. Any wording changes to this guide belong to the group conscience of those who use it.
